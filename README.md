# Referral Solutions Hub

Member hub for BNI Referral Solutions (Pasadena): meeting details, chapter calendar, power teams, networking ribbons, new-member onboarding, the 2026 4-Star Networker path, quick access links, and a BNI cheat sheet.

## Files

- `index.html`: the whole site (Tailwind + Lucide from CDN, no build step)
- `images/chapter-group-photo.jpg`: hero photo. **Add this file**; the Canva image reference couldn't be carried over.
- `.nojekyll`: tells GitHub Pages to serve files as-is

## Publishing

Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
The site will be live at `https://oliviathaipersonal.github.io/referral-solutions-hub/`.

## Editing

Edit `index.html` directly on GitHub (pencil icon) and commit. Pages redeploys in about a minute.
